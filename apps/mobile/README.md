## 在这台电脑和手机上使用

1. 在Android手机安装 `D:/.Workspace/医工/OPMDMobileDemo/distribution/app-debug.apk`，也可打开 `http://www.ming56.cn:9020/download` 下载。
2. 电脑双击 `D:/.Workspace/医工/启动手机APP服务.cmd`。保持窗口打开；窗口显示地址与连接口令。
3. 此APK预填公网服务地址和现有口令，手机无需与电脑连接同一Wi-Fi。电脑服务和NPC均需保持运行；需要修改连接时进入“我的→连接设置”。
4. 首次使用进入“我的→新建档案”，填写代号；再点“新增”填写本次情况，从相册选择照片，按实际资料填写检测数值。应用不再自动填入就诊数据。
5. 自己录入时，可在最后一步点“保存并分析”，或单独提交给医生。模型预测与医生反馈分别显示。

若已有服务占用8765端口，继续使用原窗口，或关闭原窗口后再启动。手机无法连接时检查电脑网络是否允许本服务；不需要开放互联网端口。演示调试包支持局域网HTTP，正式版本需另行配置加密部署和身份认证。

## 补照片与医生反馈

医生要求补照片后，患者首页显示关联任务。点“去补充资料”→拍照或相册选择→核对→提交。任务由医生实际填写，不再提供预置档案。

在“我的→医生工作台”打开等待复核的补充记录，填写复核人代号、意见，确认发送。回到患者页查看反馈。患者与医生均可进入分析页，按钮统一为“分析”；运行失败时保留资料并显示原因。

资料任务：待补充→已提交→医生确认。线下复诊只记录患者自报完成。不同就诊、部位独立保存；修改后需要重新复核，旧反馈及研究结果留在历史。

## 医生查看判断依据和补资料前后变化

“我的→医生工作台→打开记录→查看分析”。新分析完成后，医生页增加：

- **本次判断依据：** 切换正常/轻度、中度、重度，查看照片、病史及检测资料分别推高或拉低分数多少；不再展示内部的分级步骤。
- **资料一起使用的影响：** 默认折叠，展示当前类别的成对交互。它解释模型行为，不等于补充某项检查就能判得更准。
- **补资料前后：** 同次就诊较早版本，或明确关联的补资料任务来源，可对照前后等级、三类分数和输入变化。更换模型、部位或同次记录日期后，不自动混算。此处不判断病情是否进展。
- **历史记录：** 点选查看当时保存的结果；旧结果不会补造解释。旧分析未记录完整输入信息时提示无法对照，新分析开始保存这些信息。

检测字段填写并保存后直接参与分析，报告附件、日期、取材部位和来源备注选填。DNA需要异常细胞数、总细胞数和DI阈值，才能形成模型输入。当前APP继续使用冻结的普通三分类模型。解释自动随新分析保存，患者原有分析入口保留。

- 手机：输入草稿、未发送医生意见、待上传附件，使用应用私有文件存储。切换页面或重启可恢复。
- 电脑：默认 `D:/.Workspace/医工/OPMDMobileDemo`，包含SQLite、附件、配对口令及研究运行记录。
- 已提交数据保存在电脑服务，断网时可继续整理手机草稿。当前角色切换尚未接入独立账号权限。
- 报告PDF/JPG/PNG，单文件20MB以内；拍照使用系统相机，图片保留上传原始字节。
- 拍照页仅保留系统拍照和相册选择。模拟器的OPMD相簿中已按用户指定导入3张病损原图，不自动创建记录或填写报告。Android系统相机接口已接入，真实手机拍摄仍需在实际设备确认。
- 系统在相机或文件选择过程中回收APP时，输入草稿仍保留；尚未返回的拍摄结果可能丢失。可点“新增”恢复草稿并重新拍摄或选择。自动回到拍照步骤尚未稳定复现。
- 检测字段保存后可直接分析。空值保持缺失；DNA真实零值与0/0不同。历史分析保留，需要重新分析才会使用修改后的资料。

## 构建与复现

Node 24、Java 21、Android SDK API36；锁定npm依赖。当前SDK位于 `D:/.Workspace/android-sdk-opmd`。

```powershell
./build-android.ps1
```

APK输出：`android/app/build/outputs/apk/debug/app-debug.apk`。源码在 `master` 分支。电脑服务与共用推理代码已合并到同级 `server` 目录，部署模型在项目根目录的 `models/app`。

默认构建内置公网服务地址`http://www.ming56.cn:9020`，并读取`D:/.Workspace/医工/OPMDMobileDemo/pairing-token.txt`中的现有口令。`-ServiceUrl`可指定其他地址，`-NoDefaultConnection`生成不含连接凭据的包；口令不写入跟踪源码。生成的网页资源已忽略，不提交Git。

手机服务的`/download`及`/download/app.apk`提供当前安装包，不要求输入口令；其他数据接口仍要求配对口令。分发文件保存在电脑服务私有目录的distribution中。更换IP或口令后，在连接设置修改或重新打包。

浏览器检查脚本和Android检查脚本使用当前电脑的Playwright运行时，输出独立证据目录；Android脚本控制调试WebView，系统相机/报告选择使用adb检查。它们属于工程验收，不是医生评审或真人用户试用。
