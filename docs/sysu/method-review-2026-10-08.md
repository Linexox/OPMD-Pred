# SYSU 方法质疑与查新审计

日期：2026-10-08。审阅对象：`docs/sysu/method-proposal-2026-10-08.md`。本文件不修改方案，不运行模型、测试或 GPU；数值例子均为人工有限求和。审阅结论：**数学连接成立，创新表述需收窄；一致性保留为低权重、可否决的独立实验，默认 λ=0，不作为已经验证的主模型组件。**

修订状态：本审计的初稿针对绝对累计差训练项；协调者随后已把它降为 λ=0 的风险对照，推荐候选改为平方累计匹配/teacher→student KL，并补了动作固定及归一化交互非线性说明。本文保留原案反例作为决策依据，第6节核验修订后的理想条件结论；平方/KL仍没有SYSU效果证据。

## 1. 数学逐项核对

### 1.1 合法概率、有序距离与期望恒等式

类别取 `{0,1,2}`，累计概率 `q1=P(Y≥1)`、`q2=P(Y≥2)`。要求 `1≥q1≥q2≥0`，于是 `p=(1-q1,q1-q2,q2)` 合法。

两分布的 CDF 在 `[0,1)` 和 `[1,2)` 各为常数，因此单位类别间距下：

```
W1(pO,pS) = |qO1-qS1| + |qO2-qS2|.
```

这是已有一维 Wasserstein 公式的三点特例。[Vallender/Vallander，1973 原文 / 1974 英译，DOI 10.1137/1118101](https://www.mathnet.ru/eng/tvp4387)。它不是 squared EMD，也不是 `W1²`。如果类别间距为 `d01,d12`，必须改为 `d01*|Δq1|+d12*|Δq2|`；“一级距”和“医学代价”不是同一个概念。

直接展开：

```
Σ p_y*g_y = (1-q1)g0+(q1-q2)g1+q2*g2
          = g0+(g1-g0)q1+(g2-g1)q2.
```

令 `L=max(|g1-g0|,|g2-g1|)`，则 `|EO[g]-ES[g]|≤L*W1`。不要求 g 单调或非负；合法三分类概率足够。更紧的直接界是 `|g1-g0|*|Δq1|+|g2-g1|*|Δq2|`，可以一起报告，不必只用最大斜率。

### 1.2 动作差的稳定性

固定代价矩阵 C、固定动作 a 和竞争动作 b，`g_y=C[y,b]-C[y,a]`，`G_ba(p)=R_p(b)-R_p(a)`。因此 `|G_ba(pO)-G_ba(pS)|≤L_ba*W1`。若原视图下每个竞争动作都满足 `G_ba(pO)>L_ba*W1`，则子视图中所有 `G_ba(pS)>0`，a 仍为唯一最优动作。

该条件是**充分条件，不是必要条件**。条件不成立，只表示这条界不能证明稳定，不能显示成“不稳定”或“必然换判”。实际已经算出两视图时，应直接检查动作是否变化，界用于解释可能稳定的原因。若要证明对所有可能缺失子集都稳定，要逐一检查这些子集或另有统一上界；单个子集的结果不能推广到全部子集。

人工例子，C 的行是真实类，列是动作：

```
C=[[0,1,4],[2,0,1],[8,3,0]]
pO=(.10,.20,.70), qO=(.90,.70)
pS=(.15,.20,.65), qS=(.85,.65), W1=.10
RO=(6.00,2.20,.60), RS=(5.60,2.10,.80)
```

O 中最优 a=2。b=0 时 `g=(-4,1,8)`，L=7，原动作差 5.40 > .70；b=1 时 `g=(-3,-1,3)`，L=4，原差 1.60 > .40。S 中实际差为 4.80 和 1.30，动作仍是 2。恒等式、界方向和方案中的严格不等号均正确。

**这不是患者真实病情风险的界。** `R_p` 只是模型概率与人为代价下的预测期望损失；稳定的错误模型也会通过该判据。没有 p 与真实条件分布之间的误差/校准证据，就不能据此界定真实误诊概率、重度漏诊率、疾病进展风险或缺失检测的真实临床后果。

### 1.3 SHAP 重用的两个必要限定

固定同一个背景/coalition 游戏，固定 a、b、C，对每类概率的原始 Shapley 值线性组合是正确的。未归一化的 Shapley interaction index 也是对游戏值的线性算子。[InterSHAP 原文](https://arxiv.org/html/2412.15828v2)

但需特别明确：

1. **InterSHAP 经过绝对值、总贡献分母及百分比归一化的分数不线性。** 可以重用各 coalition 的模型概率和原始交互项，再重新算动作差目标的归一化分数；不能对原本各类别的“交互百分比”直接按 C 加权。
2. **a/b 必须在全部 coalition 中固定**，例如原始病例决策 a 与固定竞争动作 b。若每个 coalition 重新选择 argmin，或解释 `min_a R(a)`、最优和次优动作之差，则目标包含非线性选取，不能套固定系数线性公式。

类似地，背景分布不能随类别改变；以 softmax logit 的 SHAP 代替概率 SHAP 会改变目标。个体依赖 C 若固定于该病例也可线性重用；若 C 随 coalition 输入一起变化，则不可。

## 3. 一致性为什么可能损害本项目最关心的重度召回

这不是实现 bug，而是观测信息减少后的统计目标冲突。只要子视图 S 无法确定老师 O 知道的内容，同一样本逐点逼近 pO 就可能要求 S 更确定，甚至偏向多数类。

人工反例：S 对所有人完全一样，真实 Y 为 0 的概率 .90、为 2 的概率 .10；O 有一个完美检查，因此 teacher 对每人都是正确的一点分布。最优校准子视图是 `pS=(.90,0,.10)`，累计 qS=(.10,.10)。

```
真实0：W1 = .10+.10=.20；概率 .90
真实2：W1 = .90+.90=1.80；概率 .10
平均W1 = .90*.20+.10*1.80=.36
```

若子模型永远给 `pS=(1,0,0)`，平均 W1 反而为 `.90*0+.10*2=.20`，更小，但重度概率被完全消掉。校准概率并不是样本级累计 L1 蒸馏的最优点。这里老师**全部正确且高置信**，所以老师正确性/置信度门控也不能排除该反例。

进一步以子模型 `pS=(1-r,0,r)` 写总目标：

```
CE(r)=-.9*log(1-r)-.1*log(r)
E[W1]=.2+1.6*r
总导数=(r-.1)/(r*(1-r))+1.6*λ
```

λ>0 时原校准点 r=.1 的总导数为正，最优 r 往低于 .1 移动。有限 CE 监督会避免 r 精确为0，但不能保证重度概率/校准不被压低。不能宣称停止老师梯度就解决该信息不对称问题。

### 其他必须保留的失败检查

- 同一模型老师并不是独立正确老师。早期偏差可能被学生复制；训练集准确 teacher 也可能只记忆139条记录。
- W1 变小与模态被忽略均可满足稳定性界。需要“加入 DNA/甲基化是否带来真实收益”的对照，不能只统计移除后不换判的比例。
- H1 如果只测“模拟移除后错误增幅”，可由原 O 性能被拉低来虚假改善，必须同时报告 O、S 的绝对性能。
- 缺失较少的模型不一定对个体更准确；额外模态可能噪声、错配、诊断后产生。只有观测集合包含关系，不保证信息/性能优越。
- 减少某人的信息后置信度可以增大或减小；要求逐病例 `entropy(S)≥entropy(O)` 也不是普适真理。可报告总体校准/置信分布，不另加硬性的同置信或熵单调约束。

## 4. 保留/否决建议和最小实验

**保留有序头、独立代价决策、概率动作差解释；保留累计 W1 一致性作为可失败的单项实验，默认 λ=0。** 不在首次底座中绑定一致性、对比、重建与教师门控。若最终无益，就删除一致性组件，仍可保留距离/动作差作为分析与可视化工具。

前置数据问题未解决时不训练。解决后同一患者协议、模型容量、开发集与预算内执行：

1. 仅 O 分类；O+S 分类监督；O+S+KL；O+S+累计 W1。λ 网格只在开发集选择，先含0与小权重。
2. 每个版本都报 O 与 S 的绝对 accuracy、重度 recall/precision、NLL/Brier、ECE、MAE、跨两级率；W1/稳定性是辅助项，不是最优化临床指标的替代物。
3. 自然缺失单独评估，模拟移除在同批患者比较。报告模式人数与覆盖率，不把模拟收益推广到不存在的甲基化观测。
4. 单独显示同一概率的 argmax 与固定 C 动作，解释 a/b 固定。检查加入关键真实检测的增益和移除后变化，保留 mask-only。
5. 用参数随机化、训练背景改变、遮挡/内容替换核验解释；原始概率/SII 可重用，所有归一化交互比例重算。

**否决标准**：重度召回/校准被压低、收益来自 O 性能恶化、自然缺失无收益、模型忽略稀少而有效的检测、或改善只能由 mask-only 复制。不用“理论稳定界成立”覆盖这些实证失败。

## 5. 对创新措辞的最终判断

可保留：“以自然观测为边界，在患者独立的三级风险分层中，联合审计缺失视图的累计概率变化、固定代价动作差及模态解释。”

应否决：“首次提出医学有序 Wasserstein 蒸馏”“首次以缺失老师自蒸馏”“首次成本敏感 SHAP”“理论保证降低重度漏诊”“缺失越多置信越低的保证”“交互百分比线性重用”。

目前真正未知的是这种组合是否在 SYSU 少量、缺失不均衡、患者可能重复的样本上有效。数学部分是已知性质的透明有限展开；方法组合的贡献需由患者级数据审计、严格对照、真实自然缺失收益与解释忠实性共同证明。

## 6. 对修订版平方匹配与条件塔式关系的核验

固定子视图信息 I_S，对**未加权**单阈值平方项：

```
E[(r-qO)² | I_S]
 = (r-E[qO|I_S])² + Var(qO|I_S).
```

因此总体最优 r 是 `E[qO|I_S]`。对合法 teacher 的两个阈值分别取条件期望仍保持有序；未受额外网络表达限制时可还原合法三分类概率。这是平方误差条件均值的基础性质，不是新定理；有限共享模型和多个联合损失不必达到该总体极小值。

要进一步等于真实子视图事件概率，必须细化理想条件：teacher 是 `P(Y≥k | I_O)`；随机子集选择变量 Z 给定 I_O 与 Y 条件独立；I_S 包含保留下来的值和其可用性 mask，且是增广信息 `(I_O,Z)` 的子信息。于是：

```
P(Y≥k | I_O,Z)=P(Y≥k | I_O)=qO
E[qO|I_S]=E[E[1(Y≥k)|I_O,Z]|I_S]
           =P(Y≥k|I_S).
```

仅“模型校准”弱于“是真实条件概率”；只把学生样本限制在某缺失组，也不自动满足上述嵌套和选择条件。模拟随机删除与医生决定是否做DNA/甲基化具有不同抽样机制，不能把自然缺失人群视为同一联合分布。

**门控注意：** 如果平方项乘以依赖 teacher、标签或观测信息的非负 w，条件最优值改成 `E[w*qO|I_S]/E[w|I_S]`（分母>0），一般不等于未加权事件概率。仅 w 在 I_S 下为固定正数，或额外证明权重不改变条件均值，才可继续使用原等式。教师正确性门控与置信门控均可能改变这一均值；“只使用训练数据”避免泄漏，但不证明加权目标无偏。

**KL方向注意：** `E[KL(pO||pS)|I_S]` 对合法 pS 的最优分布是 `E[pO|I_S]`，这是 forward teacher→student KL，允许不同病例经平均后恢复子视图不确定性。反向 `KL(pS||pO)` 一般导出几何平均并可能在 teacher 一点分布时发散，不能共享上述概率等式。模型的 soft teacher 还可能不正确，方向正确也不等于效果有保证。

修订方案已不推荐绝对W1主损失，这个改变合理。建议最小对照中优先保留未门控的平方累计/forward KL，然后独立尝试门控；W1仍用于模型动作稳定性分析。不要通过增大一致性权重追求所有个体的W或平方差为零，因为即使理想 Bayes teacher/学生，在有效检查被移除后逐病例分布不同仍是正确现象。
