# CORN与有序距离静态复核

2026-10-08。复核对象为基于e2e090f的cost-ordinal代码；不运行模型、unit tests或真实训练。初步独立代理审阅已确认条件子集、合法概率与late累计池化方向，代理后续因服务用量限制中断，未完成独立报告；以下由总代码协调者收尾，**不是完整独立运行验证**。

- CORN任务1用所有y≥0记录监督y>0，任务2仅取真实y>0记录监督y>1，BCE选出单任务logits，不使用模型预测筛选标签。
- 当条件子集为空，第二loss为0，分母N不为空；其他情况下为N+N_(y>0)。共享头有2个独立输出，q2=r1*r2不超过q1，p非负且总和1（数学结构结论，未实测浮点/梯度）。
- late先平均无条件累计概率，再重构r2=q2/q1，不把不同模式的条件概率直接平均。为logit夹极端值，属于显式数值近似；空coalition仅解释参照，不是真实病例预测。
- 平方累计距离等价预测/目标CDF平方差，既不是W1也不是W1²；它是对称有序目标，不保证偏重召回。默认λ0没有额外训练偏好。
- 沿用患者/hash协议、年龄/性别禁用、train-only TCT、覆盖率分母、argmax选epoch与独立固定测试；成本矩阵行真实/列行动，显式传入，无默认医学代价。
- 发现CORN loss的batch内条件计数导致评估loss汇总依赖batchsize。总代码已改验证/测试为全条件任务项均值，训练仍记录minibatch优化诊断，标注不同聚合规则。accuracy等类别指标不依赖这一loss归一化选择。
