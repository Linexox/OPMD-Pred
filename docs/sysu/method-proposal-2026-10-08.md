# SYSU方法主线：缺失信息下的有序风险与决策解释

日期2026-10-08；理论研究方案，尚无SYSU训练结果。用户确认三类0正常/轻度、1中度、2重度，保留图片/病史/TCT/DNA/甲基化，禁用年龄与性别。漏判偏好由用户提出，未给出临床验证的代价矩阵。

## 1. 要解决的一个问题

不同患者有不同检查组合。缺少检查时，不能把“未检测”误作“检测阴性”，也不能用全预测重度换取召回。研究问题是：在准确率≥75%的目标下，能否让部分观测模型减少严重度低估与跨两级错误，并说明哪些真实观测信息改变了概率和判定。

当前139条记录没有经核验患者ID，2组图片对应轻/中两类冲突；患者分组、图像来源及标签核对完成前不能开始可信训练评价。5条在去人口学后没有任何输入，需明确进入“资料不足”路径，不能从空输入产生普通病例预测；评价同时报告可预测覆盖率和全部样本数量。

## 2. 优先模型与对照

固定SAM-DINO B14/518/1536编码器先提取图像特征，五模态小型融合头训练。低样本阶段优先冻结图像骨干，后续是否解冻由开发集决定，不预设微调更好。DNA用已审计的异常细胞比例，甲基化先用总数；十基因panel是另一候选方向，只在实际观测支持下做独立消融。

先比较图像单模态、表格单模态、简单late fusion和现有missing-token融合。然后在同一患者协议内依次研究：观测子集监督；有序头；独立代价决策；缺失子集一致性。单次对照只改一个机制。

当前有序阈值头已保证q1≥q2。三类概率p=(1-q1,q1-q2,q2)，概率学习与决策代价分开。默认决策argmax(p)，代价方案另算a=argmin(p@C)。重度召回提升必须同时报告precision、accuracy、低估/过估、跨两级错误和预测重度比例。

## 3. 一个可落地的理论连接

下面是对离散概率的基础推导，**不是声称新的Wasserstein理论或临床风险保证**。它用于把缺失一致性、代价决策稳定性和解释目标连接到同一对象。

设O是患者实际观测模态，S⊆O是训练时移除部分观测后的视图。p_O、p_S分别是同一个模型在两个视图下的合法三分类概率。令Δq_k=q_{O,k}-q_{S,k}，k=1,2，则

```
W = |Δq1| + |Δq2|
```

这是类别间距取1时这两个有序分布的1-Wasserstein距离。任意三个数g0,g1,g2满足

```
E_p[g(Y)] = g0 + (g1-g0)q1 + (g2-g1)q2
```

因此

```
|E_O[g]-E_S[g]| ≤ max(|g1-g0|, |g2-g1|) * W.
```

给定代价矩阵C的一个动作a，取gy=C[y,a]就得到预测期望代价变化上界。比较动作a与b，取gy=C[y,b]-C[y,a]，记L_ba为相邻真实等级上gy的最大绝对差。

若a是p_O下的最优动作，并且对每个b≠a有

```
R_O(b)-R_O(a) > L_ba * W
```

则p_S下a仍严格优于b，动作不变。证明是将上一界应用于两动作风险差；严格大于排除平局。

这个判据只说明**同一模型、两个已计算视图**的决策稳定性。它不保证正确，不保证重度召回，不说明患者真实病变变化，也不能推断从未测过的模态。类别间距和C仍是研究设定。W=0只是模型没有使用移除信息，可能是鲁棒，也可能是完全忽略该模态。

## 4. 将连接变成可检验的方法假设

训练基线对O与随机非空S各算正确标签的概率损失；teacher仅用实际O，不伪造全模态。

候选一致性项为

```
L = L_probability(O,y) + L_probability(S,y)
    + λ * w(O,y) * (|q_S1-stopgrad(q_O1)| + |q_S2-stopgrad(q_O2)|).
```

w是可选的训练门控，最初设为1与λ=0对照；若使用teacher正确性/置信度，必须只由训练数据决定，且与无门控对照。图像增强与子集移除分开记录。信息减少会合理增加不确定性，因此不能把所有W都强制到0；需监测各单模态质量、类条件召回和过度置信。

独立复审发现这里的绝对差训练有明确反例：缺失视图没有信息，Y=0概率.9、Y=2概率.1，而观测teacher完美。合理的缺失概率为(.9,0,.1)，其平均W为.36；缺失视图全预测轻度(1,0,0)的平均W只有.20。teacher正确且高置信的门控无法排除此反例。因此**上述绝对差训练项默认λ=0，仅保留为可失败对照，不作为推荐主损失**；模型决策稳定性上界仍是正确的描述性结论。

优先候选为累计概率平方匹配或正向teacher分布`KL(p_O||p_S)`，保留每个子视图的真实标签监督。例如`L_consistency=Σ_k(q_Sk-stopgrad(q_Ok))²`。对固定子视图信息I_S（包含其可用性mask），**未加权平方项**的总体极小值是`q_Sk=E[q_Ok|I_S]`；正向KL的极小值为`p_S=E[p_O|I_S]`，反向KL不具有同一结论。

若teacher恰好是真实条件概率、随机子集索引在给定观测信息I_O下独立于标签，且I_S包含于(I_O,随机子集索引)的信息，则塔式关系给出子视图事件概率。若用标签/teacher置信门控w，这一平方极小值改为`E[w*q_Ok|I_S]/E[w|I_S]`（分母>0），不能继续无条件套用未加权概率等式。这些是理想假设，不是有限SYSU数据中已证实事实；自然缺失分布也不一定等于从较完整病例随机生成的视图分布。平方CDF损失/有序蒸馏已有先行工作，不宣称首创。

主假设H1：在相同模型/数据/预算下，**平方累计概率或KL**一致性比单纯模态dropout降低模拟移除下的跨两级错误增幅；绝对累计差为风险对照。反证：accuracy下降、重度precision明显恶化、真实自然缺失组无收益或mask-only捷径增强。

主假设H2：代价决策对低估有效，但稳定性指标能区别“概率改善”与“只把动作往重度移”。分别报告argmax与成本动作，不仅报告赢家。

主假设H3：针对动作风险差的模态解释，比仅连续严重度SHAP更直接说明判定理由；解释改变是否伴随实际风险差改变，用移除/替换干预检验。H3关乎解释忠实度，不是临床因果结论。

## 5. 与SHAP/InterSHAP及可视化的联系

保留q1、q2和三类概率解释，同时解释G_ba=R(b)-R(a)。由于G_ba是概率的线性组合，使用**同一coalition与背景游戏**时，Shapley线性性给出

```
φ_m(G_ba) = Σ_y (C[y,b]-C[y,a]) φ_m(p_y)
```

未归一化Shapley interaction项也可按相同线性组合重用，避免为每个成本方案重算全部模型。动作a/b和C必须在整个coalition游戏中固定；重新对每个coalition取argmin或min后的目标不再是固定线性组合。InterSHAP的绝对值/比值归一化交互百分比也不能按成本系数直接线性重用，需要先重建目标交互项再计算该指标。这里的线性性是已有性质，不是新解释算法。

解释分两种游戏：实际观测值相对训练背景的内容贡献；移除一个观测模态的可用信息贡献。自然未测模态始终未测；缺失不画成阴性。五模态最多32个coalition，空coalition只用于计算参照并标注为缺失路径的模型基线，不能显示为有效诊断。

预测页面/报告分四块：实际观测组合和资料不足提示；三类概率与预测等级；使用的成本偏好和模型概率动作差异；观测模态及交互贡献、图像IG/patch热图。图像归因需同一个DINO/518/padding/CLS+patch路径，热图映射回原图。先验证归因目标、梯度与参数随机化/遮挡对照，再设计比赛展示。

模型稳定性显示“移除已观测信息后，判定是否变化”，不能显示为“病情稳定”。conformal为后续独立校准模块，稀疏缺失组难以得到有用集合，不许把总体覆盖率说成重度召回保证。

## 6. 创新边界与前置实验

缺失token/dropout、对比融合、有序损失、代价决策、SHAP与缺失模式conformal已有文献。当前可能的研究贡献是**围绕缺失导致的严重度低估，把训练累计概率距离、决策风险差和病例解释用同一量连接，并进行患者级自然缺失/模拟移除的可证伪评价**。这是待实验检验的方法主张，不宣称首创或已优于参考论文。

不先训练大型生成模型补齐生物标志物，不把增强样本当新患者，不用测试挑成本或展示例子。缺失机制可能是医生检测选择，保持mask-only对照；对观察人群中的检测与标签关系不推断为生物学因果。

首批必要实验：患者/同图分组；mask-only；图像与表格单模态；missing-token与late fusion；dropout vs 子集监督；λ=0 vs平方累计/KL一致性（绝对累计差仅风险对照）；同概率argmax vs固定C。所有模型先统一开发集，预留测试一次固定评估。不能以现有139条随机记录划分的75%声称临床达标。
