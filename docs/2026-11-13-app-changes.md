# 口腔随访 App 患者端改动汇报

2026 年 11 月 13 日

本次更新覆盖患者从打开 App、开始自查、拍照和填报告，到核对、提交给医生和查看分析结果的流程。患者可以中途离线保存草稿，回来继续填写，也可以在自查过程中查看口腔科普。

## 患者现在怎么操作

| 环节 | 本次改动 |
| --- | --- |
| 首页和建档 | 首页提供「开始自查」。首次建立匿名档案后直接进入自查。有草稿时可从首页继续，并看到停在哪一步。 |
| 描述情况 | 新记录由患者选择口腔部位，可看图选择，也可选「不确定或其他部位」。症状输入框提示记录发现时间、疼痛和变化。吸烟、饮酒、槟榔史折叠选填。 |
| 拍照与资料 | 选好照片后直接显示，可换照或恢复上一张。取消换照会保留原图。细胞显微图和已有报告集中在可展开的检查资料区，没有报告也可继续。 |
| 录入甲基化结果 | 可逐项点选阳性、阴性，也可勾选多个基因后批量填写。填错可清除，标题显示已填项数。未填写的项目保持缺失，阴性作为明确结果保存。看不懂报告时可只添加原 PDF 或图片，请医生协助。 |
| 核对与保存 | 核对页显示照片缩略图、报告名称和已填基因项数，并可直达对应位置修改。「保存到本机，稍后继续」支持断网使用。 |
| 提交与分析 | 有可分析资料时，点击「提交给医生并分析」，系统依次保存记录、提交给医生、启动分析。暂缺可分析资料时，可以先保存记录或仅提交给医生。 |
| 查看结果和补资料 | 结果页显示医生提交状态，并提示模型结果供就诊沟通参考。查询中断时可重查原任务。医生要求补报告时，入口直接展开并定位到报告卡片。 |

## 口腔科普

- 首页「口腔健康科普」解释口腔潜在恶性疾患（OPMD）、口腔鳞癌（OSCC）以及检查和复诊的用途。展开后可以看到医生用灯检查口腔的插画。[专家共识](https://pubmed.ncbi.nlm.nih.gov/33128420/) · [美国国家癌症研究所患者指南](https://www.cancer.gov/types/head-and-neck/patient/adult/lip-mouth-treatment-pdq) · [国际癌症研究机构口腔癌预防手册](https://publications.iarc.who.int/617)
- 拍照页提供斑片、溃疡和局部凸起的观察提示。八格插画默认收起，展开后可放大。两张插画来自组内《科普资料》。[美国国家牙科与颅面研究所就诊提示](https://www.nidcr.nih.gov/health-info/oral-cancer#symptoms)

## 保存修复与验证

- 修复了已有细胞显微图或逐项甲基化结果的记录再次编辑时保存失败的问题。旧图和报告可保留，历史反馈可查看。DNA 录入和计算沿用现有规则。
- 前端类型检查和构建通过。用模拟服务及虚构档案检查了 320 和 390 像素宽度下的网页操作，并用隔离数据库验证旧记录编辑。Android 真机拍摄和线上模型联调待验证。
- 整批改动可通过撤销本次 Git 提交回退。各项操作的本机回退命令见 `docs/worklog/` 中 11 月 12 日和 13 日的日志。

## 路演下载核查

当前公开 APK 约 14.75 MB。检查安装包文件目录时，未发现单独打包的患者数据库、报告附件或模型权重。模拟首次打开时，App 会请求档案列表，并重复请求默认档案的记录和待办。安装包下载和模型 API 使用同一服务。

路演方案待讨论。建议将 APK 放到独立静态下载地址，评委体验使用独立数据和凭据，提前准备可查看的虚构示例和明确标注的示例分析结果。实际并发容量待压测。
